## Acceptance interpretation

The local TypeScript typecheck, direct core behavior, web server-render checks, Python tests, live API hashing/verification, SDK execution, and npm audit have evidence. Release acceptance remains open: normal `npm ci`, core Vitest, Vite build/dev, clean Python installation, Python/secret/code security tools, browser E2E/screenshots/accessibility/privacy inspection, GitHub Actions, and final source archive inspection remain blocked or unrun. No requirement is marked release-verified solely because code exists.
