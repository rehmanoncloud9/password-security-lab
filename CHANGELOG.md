# Changelog

## 0.1.0

Initial classroom implementation. This entry describes the repository snapshot;
JavaScript installation, build, and browser behavior remain unverified in the
supplied restricted environment. Do not treat this version as a release candidate.

- Added a framework-independent TypeScript analysis, policy, reuse, and secure
  password generation core with a React laboratory interface.
- Added a loopback FastAPI laboratory for SHA-256, PBKDF2-HMAC-SHA256, bcrypt,
  Argon2id, bounded synthetic attack strategies, and measured benchmarks.
- Added Python unit and API integration tests, privacy boundary lint, operational
  health data, an independent SDK consumer example, and engineering documentation.
- Optional exposure screening is deferred. No package or public deployment has
  been released.
